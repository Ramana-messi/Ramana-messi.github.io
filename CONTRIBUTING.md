# Contributing

Thank you for your interest in improving this portfolio.

## How to contribute

1. Fork the repository.
2. Create a new branch for your change.
3. Make your changes.
4. Test the website locally.
5. Commit your changes with a clear message.
6. Open a pull request describing what you changed and why.

## Useful contributions

Examples include:

- Accessibility improvements
- Responsive-design fixes
- Documentation improvements
- Bug fixes
- Performance improvements
- UI/UX improvements
- Browser compatibility fixes

Please keep pull requests focused on a specific improvement.

## Reporting issues

If you find a bug or have a suggestion, open an issue and include enough information for the problem to be reproduced.
